# Third-party resources

None. Asimetitos uses only plain HTML, CSS and JavaScript written for this project:
- no libraries or frameworks;
- no external images, fonts, 3D models, music or sound files;
- the 3D views are drawn in code (CSS 3D transforms and Canvas 2D);
- the sounds are synthesized with the browser's Web Audio API.

No NASA logos or insignia are used.
