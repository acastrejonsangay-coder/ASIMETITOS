# Use of Artificial Intelligence

We used Anthropic's Claude (Claude Code) as a coding assistant to:
- write the game code: simulation model, interface, 3D views, sounds and automated tests;
- suggest visual designs;
- draft documentation.

The team defined the idea, chose the design direction, played and reviewed the game, and checked the content.

No AI-generated images, video or audio are used.

This project was created during the NASA Space Apps Challenge hackathon (November 14–15, 2026) with the help of Claude Code.
